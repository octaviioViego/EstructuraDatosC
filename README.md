**Proyecto de estudio en estructuras de datos en C**

Este proyecto fue creado con el objetivo de estudiar e implementar las estructuras de datos más conocidas utilizando el lenguaje de programación C. Además, se incluyen algoritmos tanto clásicos como menos comunes, con el propósito de fortalecer la lógica de programación y la comprensión profunda de estos conceptos.

El proyecto forma parte de mi preparación para el examen de admisión a la Maestría en Ingeniería de Software de la UNAM, con la meta de desarrollar habilidades para diseñar algoritmos de alto nivel y resolver problemas complejos de manera eficiente.

**Requisitos** 
- Tener git instalado en tu ordenador.
- Tener gcc instalado en tu ordenador.
 
**Si lo quieres implemetar en tu computadora tienes que hacer esto**:

- Clona el repositorio: https://github.com/octaviioViego/EstructuraDatosC.git
- Abre el repositorio clonado con un IDE de tu preferencia
- Ejecuta el archivo ejercicios.c: gcc ejercicios.c -o ejercicio
- Corre tu ejecutable: ./ejercicio 

Trataré de dejar comentarios en el código para que, si estás interesado en estudiarlo, puedas comprender cómo funciona. ¡Gracias por visitar el repositorio!
